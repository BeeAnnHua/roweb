## 本次修正

1. **358 Relax／Relaxation**
   - 技能最大等級為 Lv1，但資料殘留五級 HP 回復陣列。
   - 依 RA `SC_TENSIONRELAX` 修正為 HP 自然恢復量 **+200%**。

2. **2003 Death Bound**
   - 技能最大 Lv10，但反擊倍率只寫到 Lv5，Lv6～10 會停在 1000%。
   - 依 RA `500 + 100 × SkillLv` 補齊為 **600%～1500%**。

3. **2309 Trample**
   - RO_WEB 改造為每級 ATK +2%，官方最大 Lv3。
   - 移除無效的 Lv4／Lv5 資料，修正為 **2%／4%／6%**，說明同步為 Lv3 共 +6%。

4. **319、320、327、328 歌唱技能**
   - Skill Core 尚殘留固定 180 秒的舊資料。
   - 已與正式 Runtime 同步：每級 30 秒、Lv10 五分鐘、每五秒持續耗 SP、可同時維持、自然回魔不停。

5. **5210 Dragonic Aura**
   - 執行公式原本正確，但 Skill Core 的來源文字少寫基礎 `+100`。
   - 已同步為 `(100 + 3650×Lv + 10×POW + 種族追加) × BaseLv ÷ 100`。
