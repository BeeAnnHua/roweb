# 彼岸花仙境 / RO_WEB V0.9.84B

## 本次更新
- 正式雲端帳號入口：登入、註冊、Email 6 位驗證碼、忘記密碼、同 Email 多帳號選擇。
- 移除 V0.9.84A 玩家畫面中的測試資訊：Supabase UID、權限、流水號測試說明等不再顯示。
- 帳號頁與角色選擇頁共用 `images/ui/character_select_background.webp`。
- 每個遊戲帳號角色槽固定為 12 格。
- 角色可選擇任意 SLOT 1～12；目標空格時移動，目標有角色時交換位置。
- 登入雲端帳號後會偵測舊瀏覽器角色，可選擇「轉移至雲端」或「稍後再說」。
- 本機角色轉移會保留原始 localStorage / IndexedDB 備份，不在成功後刪除舊資料。
- `player.js` 既有 Remote Save Adapter 已接入 Supabase：角色進度可寫入/讀取 `ro_characters.save_data`。
- 帳號共用倉庫改為每個雲端遊戲帳號獨立本機 key，並同步至 `ro_accounts.shared_save.account_storage`。
- 雲端已有較新角色存檔時，舊本機進度不會直接覆寫雲端。

## 第一次從舊版升級的建議測試
1. 將 Patch 覆蓋到目前最新版 ROWEB 根目錄。
2. 執行 `START_RO_WEB.bat`，進入 `http://127.0.0.1:8000/`。
3. 使用已驗證的遊戲帳號登入/選擇帳號。
4. 若偵測到舊本機角色，選「轉移至雲端」。
5. 角色大廳應顯示 12 格；確認舊角色等級、職業與存檔摘要正常。
6. 用「移動位置」將角色移到其他空格，或與另一角色交換位置。
7. 進入角色後進行一次正常存檔，再回角色選擇畫面確認進度。

## 目前登入注意事項
Supabase Auth 原生密碼登入需要 Email。V0.9.84B 會在本裝置記錄「遊戲帳號 → Email」登入提示，因此已在此裝置登入過後可用遊戲帳號；新裝置第一次仍提供 Email 登入入口。若要做到任何新裝置都只輸入「遊戲帳號＋密碼」，下一階段需增加安全的伺服器端帳號解析服務（不可把玩家 Email 公開查詢給瀏覽器）。
