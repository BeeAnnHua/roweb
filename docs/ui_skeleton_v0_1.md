# RO_WEB UI Skeleton v0.1

本版重點：先把 UI 骨架放上去，不追求完整功能。

## 已完成

- 1280×720 遊戲畫面容器
- 中央地圖背景讀取 maps.json
- 左上角色資訊固定顯示
- 中間玩家 / 怪物位置預留
- 怪物圖片可由 monsters.json 顯示
- 下方戰鬥紀錄固定顯示
- 下方快捷欄固定顯示
- 右上功能按鈕列
- 背包欄 / 技能欄 / 地圖欄 / 裝備欄可開關
- 視窗可拖曳
- 視窗位置會記憶到 localStorage
