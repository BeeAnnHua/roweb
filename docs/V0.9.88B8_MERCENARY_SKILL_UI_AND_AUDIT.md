# V0.9.88B8 傭兵技能 UI 與群體技能複查

## 本版 UI 範圍

- 每個傭兵欄位新增「技能設定」按鈕。
- 技能設定分為「輔助技能」與「攻擊技能」兩頁。
- 輔助頁目前只列出該分身 Snapshot 中已學會、且屬於 B7 核准白名單的 65 個群體 Buff 與 4 個群體恢復。
- 勾選結果依角色保存在 ro_web_mercenary_party_v1_* 的 selectedSupportSkills／selectedAttackSkills，不寫回分身角色雲端存檔。
- 攻擊頁保留入口但暫不開放，等待製作名單。
- 本版是 UI 與設定持久化骨架；傭兵主動施放技能 AI 尚未啟用。

## 群體技能複查結果

現行可執行友方群體技能仍為 69 招：65 個 Buff、4 個群體恢復。js/skill_engine.js 的正式白名單、B7 文件與 B8 UI fallback 名單三者一致，沒有漏接可直接執行的群體技能。

- AL_PNEUMA／25 光之障壁：依製作決議維持排除。
