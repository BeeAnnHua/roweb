# RO_WEB V0.9.80ZB — Skill Core V2

- 技能本體改為 CORE_1 / CORE_2，全域官方 Skill ID 唯一。
- 每職業技能樹拆分至 data/skill_trees。
- Runtime 由 manifest 組合技能本體與職業技能樹，舊 skills.json 僅保留相容快照。
- MC_INCCARRY 改為每級最大 HP +2%，Lv10 +20%。
- 技能視覺 SPR/ACT/cast/hit/area 暫為 null。
- 新增 Windows 本機 HTTP 啟動與停止批次檔。

注意：本版完成的是架構遷移與目前專案既有技能的去重。尚未存在於 RO_WEB 的所有 1～4 轉及擴充職業官方技能公式，仍需依 RA 原始碼逐職業驗證後加入 Core，不能以自動推測冒充完整實作。
