# RO_WEB v0.9.8 Panel Template Cleanup

## 更新重點

1. 技能欄縮小，改成更適合 1280×720 畫面的尺寸。
2. 技能欄移除 HTML 疊出的舊橫框與舊格線，只保留 UI 圖本身的 40 格。
3. 技能 icon 置中放入 40 格內，保留 Lv 標籤、+ 配點按鈕與 tooltip。
4. 初心者「基本技能」現在可點擊開啟職業 / 修練面板。
5. 右上功能列先移除獨立「職業」按鈕，職業 / 修練收進基本技能入口。
6. 左上角色資訊改用 `character_panel.webp` 作為 UI 模板，移除重複職業名稱與 ATK / DEF 顯示。
7. 裝備欄改成按照 `equipment_panel.webp` 原本 5×2 裝備格定位，移除額外疊出的格線。
8. 統計面板改成可拖曳視窗，預設關閉，位置可記憶。
9. 更新存檔 key 與 UI 位置 key，避免舊版位置/資料干擾。
10. 補上 `技能 placeholder（已於 v0.9.64c 退休）`，清理刪除舊技能圖後可能造成的 fallback 缺圖。
