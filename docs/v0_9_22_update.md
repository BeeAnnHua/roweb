# RO_WEB V0.9.22 Update

## UI 架構整理
- 背包欄新增 `inventory-grid-wrapper`，讓格子區域獨立於分頁與底部按鈕。
- 背包外框不再包住上方分頁與下方整理 / 分解 / 鎖定按鈕。
- 背包維持每分類 100 格，5 × 4 可視區，超出使用右側捲動。

## 鎖定模式修正
- 鎖定模式關閉時，不顯示任何鎖定框。
- 鎖定模式開啟時，每個有物品的格子都顯示可辨識的小標記。
- 已鎖定物品顯示高亮標記，未鎖定物品顯示空標記。
- 修正 501 / 502 看起來像未按鎖定就出現框框的問題。

## 裝備欄修正
- 裝備欄 X 關閉鈕更貼近右上邊框。
- 裝備 icon 維持置中。
- 移除重複的 headTop slot 結構，避免頭上欄位重複。

## 版本
- 更新版本號為 V0.9.22。
- UI 位置記憶 key 更新為 `ro_web_ui_positions_v0_9_22`。
