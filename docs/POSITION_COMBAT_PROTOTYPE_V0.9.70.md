# RO_WEB V0.9.71 Position Combat Prototype

本版是座標戰鬥試驗版，不推翻原有狩獵流程，先在目前 1280x720 平面地圖上加入最小可用的 Position Engine。

## 已加入

- 玩家位置：`player.position.x/y`
- 玩家點擊地圖移動：滑鼠 / 手機點擊戰鬥區可移動
- 怪物位置：怪物出生時隨機產生 `monster.position.x/y`
- 射程判定：
  - 近戰普攻需靠近
  - 弓類武器可遠距離攻擊
- 怪物追擊：參考 RA mob_db 概念欄位
  - `AttackRange`
  - `SkillRange`
  - `ChaseRange`
  - `WalkSpeed`
  - `Ai`
  - `Modes`
- 蒼蠅翅膀真正瞬移：使用後在目前戰鬥區隨機座標移動
- 出生 / 舊存檔首載贈送蒼蠅翅膀 x100
- 自動戰鬥設定新增：找不到可鎖定目標 1 秒 / 3 秒後自動瞬移

## 暫時簡化

- 尚未做障礙物 / 不可行走區 / A* 尋路
- 尚未做地板技能範圍
- 尚未做詠唱中是否可移動的規則
- 目前怪物仍維持單隻戰鬥目標，尚未改成多怪同場
- 自動瞬移目前主要作用於擊殺後等待下一隻怪物期間；未來多怪同場後會改為「附近無可鎖定怪物」判定

## 後續建議

下一版應先決定 Position Engine 憲法：玩家移動、怪物巡邏、自動尋怪、地板技能、射程、掉落物座標與 NPC 點擊範圍。
