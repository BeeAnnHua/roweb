# RO_WEB V0.9.77a Map MVP

## 目的
先驗證「512x512 單格地圖 + 24px 世界地圖角色 + 點擊移動」的比例感。

## 本版內容
- 以 V0.9.77 為底，保留大地圖 Camera / 世界座標改動。
- 新增 `mjolnir_chunk_mvp` 測試地圖。
- 新增 `images/maps/backgrounds/mjolnir_chunk_005_bg.webp`。
- 新增 `images/maps/thumbs/mjolnir_chunk_005_small.webp`。
- 新增 `images/player/world/novice_male_24.png`。
- 測試地圖暫時隱藏怪物與戰鬥特效，只測玩家比例與點擊移動。

## 測試方式
進入遊戲後預設會進入「妙勒尼單格測試」。點擊地圖任意位置，確認 24px 人物移動比例是否舒服。

## 注意
這版不是完整大地圖系統，只是世界地圖比例 MVP。
