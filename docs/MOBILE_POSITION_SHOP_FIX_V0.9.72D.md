# RO_WEB V0.9.72d Mobile / Position / Shop Fix

## 更新重點

- PC 與手機的可走範圍改為動態計算，盡量使用整張戰鬥畫面。
- 上界避開左上角色資訊欄，下界避開戰鬥紀錄與快捷欄。
- 等待怪物出現的「?」不參與邊界與可鎖定判定。
- 手機版背包格子區置中，修正手機上偏左。
- 手機版商店購買窗重新整理為商品清單與明細區，不再由固定購買按鈕覆蓋物品說明。
- 金幣列點擊後顯示完整 Zeny / 藍寶石 / 紅寶石，3 秒後自動關閉。

## 注意

此版本仍保留 V0.9.72 系列 Position Engine 架構，主要調整座標邊界與手機 UI 參數。
