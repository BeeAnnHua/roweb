# v0.9.35 技能窗與快捷欄調整

- 技能配點改為暫存制：點技能 + 不再立刻確認。
- 技能窗右下角新增「確認配點」與「初始化」。
  - 確認配點才會跳出確認視窗並正式消耗技能點。
  - 初始化目前先取消尚未確認的暫存配點；未來可接技能重置道具。
- 左側技能分頁改為一轉 / 二轉 / 三轉 / 四轉。
- 初心者技能移到技能窗左上列，普通攻擊也放在同列供玩家拖曳。
- 技能內容區固定高度並保留右側滾動，避免技能窗過大爆版。
- 快捷欄改為玩家手動拖曳制。
  - 不再自動放入已學技能。
  - 不再預設 9 / 0 為補品。
  - 主動 / Buff / Heal / Support 技能可拖曳。
  - 被動技能不可拖曳。
  - 消耗品可從背包拖曳到快捷欄。
  - 右鍵快捷欄可清空格子。
