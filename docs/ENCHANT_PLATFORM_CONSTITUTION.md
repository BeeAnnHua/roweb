# RO_WEB 共用附魔平台憲法

版本：0.9.82GW

## 永久核心規則

1. 所有可附魔武器、防具與特殊裝備，一律使用同一套共用附魔平台。
2. 第1洞永久屬於卡片系統，不參與附魔。
3. 附魔順序固定為 **第4洞 → 第3洞 → 第2洞**。
4. 前一洞未完成時，後續洞位必須鎖定，不能提前附魔。
5. 右側清單只顯示當前洞位可用附魔，但不依目前角色職業過濾；玩家可以替分身製作後放入共用倉庫。
6. 第4、3、2洞全部完成後，只保留升階、重置與查看既有卡片／附魔。
7. 未來新增附魔裝備只新增資料池、材料、Zeny、升階及重置規則，不重做另一套 UI。

## UI 固定契約

- 左側：裝備小圖、精煉值、名稱、D/C/B/A 階級。
- 中央：裝備大圖與四個固定洞位；1左上、4右上、2左下、3右下。
- 已有卡片／附魔顯示正式圖示；左鍵點擊後鎖定並開啟名稱與完整效果資訊窗。
- 右側：目前洞位全部合法附魔石；游標預覽、左鍵鎖定。
- 下方：材料、持有／需求數量、Zeny 與確認執行。
- 只有洞位合法、已選附魔、材料足夠及 Zeny 足夠時，確認按鈕才亮起。

## 圖片安全規則

缺少任何必要圖片時，必須立即停止該部分更新並向使用者回報缺少的 ID／檔名；不得使用錯圖、占位圖或自行猜測替代。

## 0.9.82GW 邊界

本版只建立憲法、斐揚 NPC 與可操作的 UI 風格預覽。固定示意資料不讀取玩家背包，不消耗材料、不修改裝備、不保存任何附魔。黯淡冰晶武器正式附魔功能留待下一版。
