# RO_WEB V0.9.85B — 遊戲內信箱 / GM CENTER

## 本版重點

- 一般玩家只看得到「信箱」，不顯示 GM 按鈕。
- GM CENTER 必須由目前選中的 GM RO 帳號開啟；同 Email 下的普通帳號不會繼承 GM 權限。
- GM 日常寄信直接在 GM CENTER 操作，不需要每封信都開 Supabase SQL Editor。
- 指定收件人使用 Player ID，例如 `100010`；不使用 Supabase Auth UID。
- 附件：最多 5 種 Item + Zeny + 藍寶石 + 紅寶石。
- 玩家領取附件後，會先寫入角色資料、完成雲端存檔驗證，再把郵件標記成已領取；保留防重複收據。

## 信箱開通歡迎信

執行本版 SQL 後，所有目前啟用中的 RO 帳號會各收到一次：

- 標題：`信箱系統正式開通！`
- 寄件人：`彼岸花仙境營運團隊`
- 附件：`紅寶石 ×100`
- 無期限

未來新建立的 RO 帳號也會透過資料庫 Trigger 自動收到同一封信。`system_key=mail_open_welcome_v1` + 唯一索引避免重複補發。

## Supabase

只需要在安裝/升級版本時執行：

`supabase/V0.9.85B_MAIL_GM_CENTER.sql`

日後 GM 寄送郵件時，底層仍透過 Supabase RPC 儲存，但 GM 不需要進 SQL Editor。

## 建議測試

1. 以一般玩家 `100010` 進遊戲：只應看到「信箱」，不應看到 GM。
2. 打開信箱：應看到「信箱系統正式開通！」，附件紅寶石 ×100。
3. 使用想領獎的角色領取，確認右上紅寶石 +100；重新整理後不可再次領取。
4. 切換到 GM01 / `100001`：應看到 GM 按鈕。
5. GM CENTER 指定 Player ID `100010`，測試寄 Zeny / 藍寶石 / 紅寶石 / Item。
6. 再切回 `100010` 收信並領取。
7. 同一 Auth Email 若同時有 GM 與一般帳號，切到一般帳號時仍不得開 GM CENTER。
