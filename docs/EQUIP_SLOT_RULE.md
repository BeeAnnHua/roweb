# RO_WEB Equip Slot Rule v0.9.33

## 基礎裝備槽

| Slot | 中文 | 備註 |
|---|---|---|
| `headTop` / `HEAD_TOP` | 頭上 | 一般頭上裝備 |
| `headMid` / `HEAD_MID` | 頭中 | 墨鏡、眼鏡等 |
| `headLow` / `HEAD_LOW` | 頭下 | 口罩等 |
| `weapon` / `RIGHT_HAND` | 武器 | 目前 runtime 使用 `weapon` |
| `shield` / `LEFT_HAND` | 盾牌 | 雙手武器未來會佔用 |
| `armor` / `BODY` | 身體 | 鎧甲、衣服、袍子 |
| `garment` / `GARMENT` | 披肩 | 斗篷類 |
| `shoes` / `SHOES` | 鞋子 | 鞋、靴 |
| `accessory1` / `ACC_L` | 飾品 1 | 飾品左/第一格 |
| `accessory2` / `ACC_R` | 飾品 2 | 飾品右/第二格 |
