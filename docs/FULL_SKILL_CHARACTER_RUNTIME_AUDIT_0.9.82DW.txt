四、本輪發現並修正的技能 Runtime 問題
-------------------------------------------------------------------------------
1. 舊 skillType 與正式 Handler 不一致
- 177 筆技能資料存在舊類型漂移。
- UI、快捷欄、被動統計改以正式 Runtime Handler 為權威。
- 可用主動快捷技能共 611 招。

2. 射程資料解析
- 正式支援 RA 負數射程與按等級排列的 Range 資料。
- 蒼鷹之眼 Lv10＋弓基礎射程仍驗證為 15 格／540px。

3. 技能延遲狀態
- 補齊每招獨立冷卻、共通延遲、走路硬直與施法狀態。
- 快捷欄與自動戰鬥使用同一套時序與阻擋訊息。

4. 自動戰鬥流程
- 成功使用治療／Buff 後，同一 Tick 不再額外追加一次攻擊。
- 自身 Buff、演奏、Toggle 關閉、Replay／Encore 的判定統一。
- 技能前置失敗不扣 SP、不進冷卻，也不錯誤回退普通攻擊。

5. 被動與主動素質效果
- 補齊 STR／AGI／VIT／INT／DEX／LUK 百分比與 allStatsRate。
- 補齊 Aura Blade mastery ATK。
- 補齊下一次物理攻擊倍率並在使用後消耗。
- 補齊移速懲罰與 MaxHP／MaxSP 相關倍率。

6. 盾牌／武器精通與元素
- 盾牌需求只有實際裝盾時生效。
- 信任的聖屬性抗性正式進入元素減傷。
- Spear and Sword Mastery 的武器傷害倍率正式進入普通攻擊與物理技能。
- Shield Mastery 的 DEF 與盾牌技能攻擊加成正式生效。
- Piety 可把玩家防具屬性改為 Holy。
- 風之紋章 Lv3 對風屬性魔法的共通延遲 -50% 正式接入時序層；非風技能不受影響。

7. 防禦與反應效果
- Guardian Shield 建立依 MaxHP 比例計算的實際吸收池。
- Auto Guard、Parry、魔法迴避、物理格擋、物理反射正式進入怪物攻擊流程。
- 長距離物理減傷、最終傷害減免、受到傷害倍率正式生效。
- 防具元素、狀態免疫與指定技能 Miss 機率正式讀取 Runtime Buff。

8. 突破極限後遺症
- 主 Buff 到期或因 SP 不足提前中止時，建立 10 秒後遺症。
- 後遺症期間自然 HP／SP 回復停止，移動速度 -25%。
- 10 秒後自然回復自動恢復。

9. 死亡動畫
- HP 歸零後不再立即補滿，先播放完整 Dead 4 幀。
- Dead 停在最後一幀，恢復 HP 後才解除死亡鎖定。
- Hurt 仍共用 Dead 前 3 幀。
- 動態測試確認播放序列可到達 Frame 3 並持續停留。

10. 普通攻擊 Proc
- 補齊附魔劍追加魔法傷害、下一擊倍率、受傷解除狀態、偽裝解除、能量取得及鷹／狼／魔力拳／自動念咒 Hook。
