# RO_WEB V0.9.64 — Skill Path Highlight + Mobile Battle Fix

## 本版定位
本版是技能樹前置路徑顯示與手機可玩模式修正版。

## 更新內容

### 技能樹前置路徑
- 滑鼠移到有前置需求的技能時，會以紅金色路徑線連到前置技能。
- 目前 Hover 的技能會亮金框。
- 前置技能改用粗框與白金描邊，避免被可學習 Glow 效果吃掉。
- 紅線只作為視覺提示，不改變技能學習判定與數值邏輯。

### 技能 ICON 試作方向
- 技能 ICON 美術風格仍屬試作，不納入正式憲法規格。
- 可參考黑金框、低飽和、清楚剪影、RO Classic HD 的方向。
- 技能狀態仍由 CSS / JS 控制，不把狀態效果寫死在圖片裡。

### 手機可玩模式
- 小螢幕下，人物與怪物位置往中間收，避免怪物跑出畫面。
- 金幣 / 寶石列在小螢幕中調整到可視範圍內。
- 手機 Battle Log 高度縮小，保留核心戰鬥訊息。
- 相關設定只在窄螢幕 media query 啟用，不影響 PC 版 1280×720 觀看效果。

### 快取版本
- 全部 CSS / JS 引用版本號更新為 `?v=0.9.64`。
