# RO_WEB V0.9.56 Shop Window Hotfix

## 更新內容

- 以 V0.9.55 為基底修正商店 UI 高度不足問題。
- 加大 `#shop-window` 視窗寬度與高度，讓商品資訊、數量、總價、確認購買區塊更完整。
- `shop-window-body` 改為可垂直捲動，避免視窗底部裁切。
- `shop-detail-panel` 加入右側滾輪，物品介紹與購買內容過長時可捲動查看。
- `shop-detail-desc` 保留獨立右側滾輪，長物品說明可單獨查看。
- 加入小螢幕保護 media query，避免固定高度導致視窗超出瀏覽器底部。
- `index.html` 全部 CSS / JS `?v=` 更新為 `0.9.56`。
