# RO_WEB V0.9.17 更新內容

## 主要修正

1. **物品欄 CSS 版重排**
   - 重新設計為 5 × 8 = 40 格。
   - 格子距離縮小，物品 icon 置中。
   - 數量固定在右下角。
   - 鎖定框 / 鎖頭固定在右上角。
   - 整理 / 分解 / 鎖定與翻頁位置重新整理。
   - 保留拖曳視窗能力。

2. **裝備欄 CSS 版重排**
   - 裝備 / 時裝 / 稱號分頁改為統一黑金 CSS 按鈕。
   - 裝備格改為 5 × 2 緊湊排列。
   - 武器 icon 放大，避免短劍太小看不清楚。
   - 裝備 tooltip 保留。
   - 時裝 / 稱號頁面保持乾淨空白。

3. **技能欄 CSS 細修**
   - 技能格改成正方形。
   - 技能 icon 更貼近格子中心。
   - 隱藏格內技能名稱，讓技能欄更接近 icon 格。
   - 保留 Lv 角標、+ 配點按鈕與 tooltip。

4. **素質欄修正**
   - STR / AGI / VIT / INT / DEX / LUK 標籤移除白底。
   - 改為深棕黑金底、金色字、細金框。
   - 維持能力值 / 戰鬥能力兩欄配置。

5. **版本更新**
   - `SAVE_KEY` 更新至 V0.9.17。
   - `UI_POS_KEY` 更新至 V0.9.17。
   - `index.html` 版本參數更新至 `?v=0.9.17`。

## 保留功能

- 可直接雙擊 `index.html` 啟動。
- 200 倍 Base EXP / Job EXP / 掉寶率 / Zeny 測試倍率保留。
- item ID 官方化修正保留。
- 技能 / 物品 / 裝備 tooltip 保留。
