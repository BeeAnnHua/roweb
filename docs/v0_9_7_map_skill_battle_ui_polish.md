# RO_WEB v0.9.7 Map / Skill / Battle UI Polish

本版針對 v0.9.6 的實測截圖進行 UI 與狀態修正。

## 更新重點

1. 地圖 / 傳送面板放大，右側傳送點不再超出 UI 框。
2. 地圖面板底部長條改為目前位置顯示：城鎮顯示「目前城鎮：XXX」，野外顯示「野外地圖：XXX」。
3. 進入城鎮時清除怪物殘留，不再顯示問號、Lv.- 或 HP 0/0。
4. 右上功能按鈕「自動」改為「戰鬥」，面板標題改為「戰鬥設定」。
5. 開始 / 停止戰鬥按鈕移進戰鬥設定面板，避免浮在主畫面上干擾其他 UI。
6. 技能欄 40 格定位微調，技能點數數字位置重新對齊。
7. 技能 tooltip 改為 RO_WEB 版本文字，避免顯示過多內部 key。
8. 職業 / 修練面板改回黑金風格，修正白底與原生白色 scrollbar。

## 備註

素質欄維持 v0.9.5 後的 UI 模板定位，不做大改。
