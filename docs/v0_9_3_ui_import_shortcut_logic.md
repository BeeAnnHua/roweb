# RO_WEB v0.9.3 UI Import & Skill Shortcut Logic

## 本版重點

1. 導入更多 UI 圖片：物品欄、技能欄、地圖欄、裝備欄、快捷欄、上方貨幣條。
2. 快捷欄改為 JS 動態產生，不再於 index.html 寫死劍士技能。
3. 初心者階段快捷欄只顯示普攻與可用消耗品。
4. 轉職後，技能會出現在技能欄；技能 Lv 1 以上才會進入快捷欄候選。
5. 自動戰鬥預設不再指定 SM_BASH，避免尚未轉職/尚未學會就出現劍士技能。
6. 新增 `啟動遊戲.bat`，讓本機可用 Python HTTP Server 啟動，避免直接雙擊 index.html 時 fetch JSON 失敗。

## 測試重點

- 初心者開局快捷欄不應出現狂擊、怒爆、霸體。
- 轉職劍士前，技能欄顯示初心者提示。
- 轉職劍士後，技能欄顯示劍士技能。
- 技能點到 Lv 1 後，該技能才出現在快捷欄。
- 使用 `啟動遊戲.bat` 或 VS Code Go Live 啟動。
