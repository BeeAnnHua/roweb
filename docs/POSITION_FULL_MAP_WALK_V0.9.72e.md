# RO_WEB V0.9.72e - Full Map Walk + UI Fade

## 決策

- 玩家可走範圍 = 整張背景圖片。
- 怪物出生範圍 = 整張背景圖片。
- Position 座標代表腳底中心 / 1 Cell，不使用整張人物圖片寬高限制座標。
- 左上角色欄、右上按鈕、金幣列、戰鬥紀錄、快捷欄不再縮小可走範圍。
- 角色進入 UI 覆蓋區時，該 UI opacity 變成 0.3；離開後恢復。

## 注意

這版目標是解除過度保守的安全邊界，讓 Position Engine 更接近 RO 的整張地圖行走感。若之後需要精準碰撞，應以 Cell / 地形遮罩處理，不再用 UI 邊界限制。
