RO_WEB V0.9.87L 安裝說明
==========================
基準：V0.9.87K

1. 將本 Patch 內容直接覆蓋到目前 GitHub / roweb 專案根目錄。
2. 不需要執行任何新的 Supabase SQL。
3. 不要清除 localStorage / IndexedDB。
4. 上傳完成後建議重新整理一次頁面，L 版已更新 style.css 與 account_menu_runtime.js 的 cache key。

本版修正：
- 修正「遊戲設定」右上 X 按下後仍顯示的 CSS hidden 優先權問題。
- 尺寸控制改為右上單一緊湊按鈕：小 / 中 / 大循環切換。
- 保留視窗拖曳、內容滾動、位置/尺寸記憶。
- 不修改 OFFLINE/CLOUD、拍賣、VIP、倉庫、信箱、MVP OOM 等其他系統。
