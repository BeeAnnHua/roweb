彼岸花仙境 RO_WEB V0.9.87A｜拍賣交易所 V1

安裝順序：
1. 先在 Supabase SQL Editor 建立 New Query。
2. 貼上並執行：supabase/V0.9.87A_AUCTION_HOUSE_V1.sql
3. SQL 最後應顯示：V0.9.87A_AUCTION_HOUSE_V1_READY
4. 再將 Patch 檔案覆蓋目前網站版本。
5. 不要清除 localStorage / IndexedDB。
6. V0.9.86Q VIP SQL 不需要重跑。

V1 規則：
- 同帳號最多 5 件同時上架。
- 上架 24 小時。
- 商品總價 <= 1,000,000：1 藍寶石。
- <= 10,000,000：2 藍寶石。
- <= 100,000,000：3 藍寶石。
- > 100,000,000：5 藍寶石。
- 上架費無論取消、到期、售出皆不退。
- 成交稅 5% Zeny；賣家實收 95%。
- 紅寶石目前不作必要交易成本。
- 成交商品與款項由遊戲信箱安全交付。

第一輪建議測試：
A. 一般堆疊材料上架 2 個 → 取消 → 信箱領回。
B. +精煉裝備上架 → 另一帳號購買 → 信箱領取後確認精煉／卡片／附魔不變。
C. 100 萬、1000 萬、1 億、1 億以上各測一次藍寶石費用。
D. 成交 100,000 Zeny → 賣家信箱應收到 95,000 Zeny。
