## RO_WEB 0.9.82HN — 防回檔耐久存檔版

本版以 0.9.82HM 為基準，優先修正長時間掛機後 F5／重新開頁可能回到舊進度的問題。

### 本版重點
- 主存檔與安全備份均在寫入後重新讀回驗證。
- 載入不再固定先讀主檔，而是比較主檔、備份、IndexedDB 與未來後端候選，選擇最新有效版本。
- 每 60 秒保存，並在頁面隱藏、F5、關頁、凍結前同步補存。
- 最新分頁擁有唯一寫入權，舊分頁不能覆蓋較新的掛機成果。
- IndexedDB 保存最新與上一代快照，localStorage 異常時仍有第二層復原來源。
- 後端同步接口已預留；目前沒有後端時完全以離線本機模式運作。
- 測試倍率統一：Base EXP／Job EXP／Drop／Zeny／Card／Map Exclusive／Grade Material 全部為 `10000`。

## RO_WEB 0.9.82HM — 貨幣列原地展開修正版

本版以 0.9.82HL 為正式基準，專門恢復右上貨幣欄原本的「點擊後在原位置展開完整數量」操作。

### 本版重點
- 不再依賴額外的「持有貨幣」浮動視窗，直接在既有右上 `#top-bar` 原地展開。
- 收合狀態維持 Zeny／藍寶石／紅寶石三格精簡排列。
- 點擊整個貨幣欄後，改為三列完整顯示名稱與完整數字；再點一次、點擊外部或按 Escape 即可收合。
- 使用 document capture 的 `pointerup`／`click`、HTML inline onclick 與鍵盤 Enter／Space 三重入口，避免早期 HUD 點擊程式攔截。
- 完整數字使用獨立顯示節點，因此角色 UI 更新時不會被舊的精簡數字重繪覆蓋。
- 保留 0.9.82HL 已成功的貨幣滑鼠提示，以及消耗品／裝備／一般道具 Tooltip 修正。
- 保留 HH～HL 的附魔、升階、地圖滾輪、NPC 玩家文字與正式出生背包規則。

歷史更新／測試／稽核紀錄已續寫至 `HISTORY_UPDATE_AUDIT_LOG_THROUGH_0.9.82HL.txt`。

### 從 0.9.82HL 使用增量包更新
覆蓋檔案後，請在專案根目錄執行一次 `APPLY_0.9.82HM_CLEANUP.bat`，移除上一版留在根目錄的 HL 報告與清理腳本。完整包不需要執行。
