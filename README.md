## RO_WEB 0.9.82IE — V92 地面特效世界座標快照修正

本版以 0.9.82ID 為基準，修正 V92 地面技能特效以玩家為基準保留固定偏移，造成玩家移動時特效一起移動。

- `GROUND_CELL` 與 `GROUND_SPAWN` 在事件真正觸發時取得目標怪物腳下的世界座標快照。
- 強酸禁地（水／地／風）的目標端 START／BOTTOM／MAIN／HIT 視覺全部固定在該次命中位置，不跟隨玩家或怪物。
- BUFF／架式／光環仍使用玩家即時座標；一般 TARGET_BODY／TARGET_FOOT 仍跟隨目標怪物；PROJECTILE_PATH 使用玩家與目標的即時端點。
- 世界座標快照每幀只依 Camera 轉成畫面座標，因此玩家移動導致鏡頭改變時，特效仍固定在原地圖位置。
- 0.9.82ID 的掛機、怪物屬性、精煉警告、肯貝特與 V92 被動技能 Gate 全部保留。
- 後續版本以 0.9.82IE 為基準。

## RO_WEB 0.9.82IB — V92 主動技能特效 Runtime

本版將 V91.6 Ready Library 正式接入 RO_WEB：55 招主動技能、454 個 Effect JSON、2395 張 PNG。施放特效會跟隨真實 Begin／Commit／Hit／End 事件，不再綁死固定毫秒。

- RO_WEB 已改造成被動的技能一律不進入特效部署；216 招被動技能有獨立稽核清單。
- 目前 55 招 Ready 候選全部仍為可執行主動技能，所以部署數維持 55；Runtime 每次事件仍會再次檢查 handler，未來改成被動時會立即跳過。
- BACK／FRONT 雙 Canvas 支援人物前後景；桌機 Full、手機 Min，並支援雙向 fallback。
- SKILL_END、死亡、換地圖、切角與離頁會清理 Loop。
- 不覆寫技能中文名稱或 RO_WEB 改造說明。
- 後續版本以 0.9.82IB 為基準。

## RO_WEB 0.9.82IA — Renewal 詠唱／延遲完整校正

本版以 rAthena Renewal 2026-06-18 為基準，校正玩家技能的變動詠唱、固定詠唱、技能後延遲、獨立冷卻與行走延遲。

- 變動詠唱使用最終 `DEX × 2 + INT`，530 時變動詠唱歸零；固定詠唱不受此素質公式影響。
- 修正通用與技能專屬固定詠唱百分比直接相加；通用來源取最強值，同技能的專屬來源先合併為候選值，再與通用／狀態候選取最高。
- 修正 `bonus2 bVariableCastrate,技能,-%` 可能誤變成全技能減免。
- 新增 `bSkillDelay` 技能專屬後延遲腳本支援。
- 補上八招連技的 `1000ms／DB 延遲 - 4×AGI - 2×DEX` Renewal 特殊公式。
- 技能詳細視窗新增目前裝備與 Buff 後的實際變詠、固詠、總詠唱、後延遲、獨立冷卻、行走延遲及 140ms 安全間隔。
- HZ 的分類傷害正規化、HY 批量開箱與 HX 耐久存檔完整保留。
- 後續版本請以 0.9.82IA 為正式基準。

## RO_WEB 0.9.82HY — 全域指定數量批量開啟

本版將箱子、轉蛋與未來卡冊統一接入共用的「指定開啟數量」架構。

- 可在物品介紹視窗輸入開啟數量，預設 100，支援 Enter。
- 輸入量超過持有量時，只處理目前持有數量，不會產生負數或空抽。
- MVP 幸運轉蛋、神秘箱子、神秘紫箱、禮物箱、黯淡冰晶武器箱與原地復活之證箱子全部適用。
- 不使用長按連開，也不建立數千個點擊事件；大量開啟會以每批 32 次切片處理並讓出主執行緒。
- 每 256 次建立耐久檢查點，完成後立即保存；手動存檔仍會先處理／安全結束待處理箱子與轉蛋。
- 新箱子與卡冊可透過共用 Adapter 註冊，不必重新修改物品 UI。
- HX 的大量轉蛋防回檔與 HW 的每件特殊獎絕對機率完整保留。
- 後續版本請以 0.9.82HY 為正式基準。
