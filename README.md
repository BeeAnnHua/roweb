# RO_WEB 0.9.82FW

本版本以 **0.9.82FV** 為基準，修正裝備／卡片實際效果串接與四轉 HP／SP 公式。

## 本版重點

- 監視者卡片等能力值卡片會實際加入最終素質，素質面板同步顯示「基礎＋裝備／卡片／技能／Buff」總加成。
- 導入目前啟用的 141 件裝備 Script Runtime；急速衝刺鎧甲的 VIT＋1、HP 自然恢復＋5%、物品恢復＋3%、受治療量＋3% 均會實際作用。
- 修正卡片／裝備的 HP／SP 自然恢復、補品恢復、物品群組恢復與受治療量串接。
- 依 rAthena Renewal 2026-06-08 的 `job_stats.yml` 補齊 13 個四轉職業與究極初學者 Lv.1～275 BaseHP／BaseSP。
- 修正轉職四轉後誤用初心者 fallback HP／SP；正常四轉與轉生系職業套用 RA 1.25 倍職業係數。
- 保留 FV 的完整卡片、插卡／拆卡、ITEM 圖示與自動掛機資源不足 15 秒防卡死。

請以 HTTP 伺服器啟動，避免瀏覽器直接開啟檔案造成 CORS 問題。Windows 可執行 `START_RO_WEB.bat`。
