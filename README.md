# RO_WEB 0.9.82FG

## 0.9.82FG 分享預覽、城鎮恢復與怪物資訊同步

- 分享連結改用明確的最小 Open Graph／Twitter 資訊，避免通訊軟體擷取遊戲內測試文字作為長篇介紹。
- 移除舊版單怪等待面板；沒有鎖定目標時不再顯示等待／搜尋怪物文字。
- 重新開啟網頁時，若存檔位於城鎮，`currentMap` 與 `player.map` 會保持空值並強制清除世界怪物 Runtime；城鎮背景不再混入野外怪物。
- 地圖怪物分布數量改為依目前 `mob_count_rate`、地區目標量與普通怪物硬上限即時計算；33% 顯示約 20 隻、50% 約 30 隻、100% 受目前硬上限顯示 40 隻。
- 稀有怪、Boss、MVP 維持獨立數量，不受普通怪物倍率縮放。
- 電腦與手機怪物分布浮卡縮小並限制高度，可使用滾輪或觸控上下滑動；每秒更新重生倒數時保留目前捲動位置。

## 0.9.82FE 怪物進場分批載入與數量調整

- Boss／MVP 重生倒數改為「X小時 X分鐘 X秒」。
- 普通怪物總量改為原本三分之一：玩家中心 1024×1024 約由 60 隻降為 20 隻。
- 地圖進入時只先建立 8 隻普通怪物，後續依 500ms 維護批次補到目標，避免同一幀建立大量實體造成卡頓。
- 稀有怪、Boss、MVP 的數量與重生規則不變。

# RO_WEB 0.9.82FD

## 0.9.82FD 世界地圖響應縮放與怪物分布懸停

- 移除進階戰鬥資訊明細中會錯位的「＋／－」占位符，明細仍可正常展開。
- 世界地圖在桌機視窗小於 1280×720 時，改用 `battle-field` 實際顯示尺寸作為 Camera Viewport；世界本體仍維持 4608×4608，不改玩家世界座標。
- 地圖／傳送的野外地區按鈕新增黑金怪物分布浮卡，依 `monster_spawn_config.json` 與 `monsters.json` 即時整理一般怪物、植物、稀有怪、Boss 與 MVP。
- Boss／MVP 可生成時以綠色顯示「存在中」；死亡等待重生時以紅色逐秒顯示「重生倒數 N 秒」。
- 城鎮按鈕維持原本的用途懸停介紹。

# RO_WEB 0.9.82FB

## 0.9.82FB 自動戰鬥精簡設定與生存功能

- 自動戰鬥設定窗移除教學式說明，保留搜尋、補給、治癒、普通攻擊、技能 1～4 與 Buff 等直接操作欄位。
- 數字欄位改為面板同色背景與金色上下三角按鈕，低血量門檻限制為 1～99%。
- 新增低血量蒼蠅翅膀逃生，以及低血量蝴蝶翅膀回城；蝴蝶翅膀優先於蒼蠅翅膀，預設返回普隆德拉。
- 新增自動解除異常狀態：先掃描已學會技能的 `clearStatuses`／`clearStatusesOnlyWhenPresent`，再掃描背包物品腳本的 `sc_end SC_*`。
- 綠色藥草、綠色藥水、萬能藥與蜂膠均已納入；未來新增的解黑暗、沉默、詛咒等技能或物品，只要資料帶有上述解除標記即可自動辨識。
- 異常解除品會保留給異常狀態系統，不會被一般 HP／SP 自動補給提早消耗；蜂膠使用時也會依 `itemheal` 同步恢復 HP／SP。
- 手動使用消耗品同樣支援 `itemheal` 與 `sc_end`，不再只依物品的固定 hp／sp 欄位。
- 保留 FA 的四技能優先序、怪物數量門檻、Buff SP 門檻、Boss／MVP 迴避與 EZ 流暢狀態機。

# RO_WEB 0.9.82EZ

## 0.9.82EZ 流暢自動戰鬥核心

- 自動戰鬥由早期單怪流程升級為 Auto Battle Controller v1 狀態機：搜尋、接近、戰鬥、補給／Buff、目標死亡與瞬移重搜各自管理。
- 正式多怪地圖擊敗怪物後立即鎖定下一隻存活目標，不再套用 legacy 單怪地圖的 1.5 秒等待。
- 目標優先序為：玩家手動強制指定、正在攻擊玩家的怪物、目前有效鎖定、其他仇恨怪與最近怪物；鎖定保持穩定，避免距離接近時反覆切換。
- 喝水、治癒與 Buff 不再依賴 currentMonster；沒有怪物時仍會正常維持生存與強化。
- 指定攻擊技能處於獨立冷卻時，預設穿插普通攻擊；Renewal 詠唱、共通延遲、動作鎖、ASPD 與 140ms 安全下限完全保留。
- 找不到目標並使用蒼蠅翅膀後，立即刷新玩家周圍怪物串流並重新搜尋。
- 手動左鍵點怪仍只執行普通攻擊；自動戰鬥開啟時，點怪會成為強制鎖定目標。


## 0.9.82EY 長讀條人物動作分段

- 有讀條的攻擊／Buff 技能不再於讀條期間循環整套 Attack／Cast。
- 讀條開始先播放前段預備幀一次，之後停在預備姿勢等待。
- 讀條完成、技能效果正式發出時，才接續最後 2～3 幀命中／施法收尾。
- 6 幀 Cast 使用前 4＋後 2；8～9 幀 Attack 保留最後 3 幀作為釋放段。
- 無讀條技能與 0.9.82EX 的技能動作分類規則不變。


## 0.9.82EX 技能人物動作修正

- 所有會對怪物造成傷害的技能，包含物理、魔法、Misc、地面、連鎖與 Combo，統一使用目前裝備武器的 Attack 動畫。
- Buff、治療、Debuff、支援、演奏、召喚施術及其他非傷害主動技能，統一使用不帶武器的 Cast 動畫。
- 被動技能不播放動作；Toggle 關閉不播放，開啟播放 Cast。
- Runtime handler 為唯一判斷來源，舊 Skill Core 的 `type: Weapon` 不再讓心神凝聚、霸體、速度激發等 Buff 誤用武器 Attack。
- 移除治療、連鎖魔法與 Combo 結算後重複播放 Cast 的硬編碼。

## 技能學習

- 點擊尚未符合前置條件的技能時，Runtime 會遞迴排列完整前置鏈，依必要順序自動加入待確認配點。
- 技能點不足時允許補到可用點數為止，但不會跳過尚未滿足的前置去學目標技能。
- 暫存配點不會立即扣除技能點；玩家按下「確認配點」後，系統才列出所有變更並正式扣點。
- 戰鬥紀錄會說明本次補了哪些技能，以及距離目標技能仍差哪些前置或 Job Level。
- 急救術及六大職業／初學者系列適用的 0～2 轉任務技能，在進入對應職業樹時直接擁有，不消耗技能點；轉生、轉職與技能初始化後會自動恢復。

## 裝備與卡片介面

- 裝備滑鼠提示只顯示 RO 客戶端風格的精簡名稱：`精煉值 + 卡片／附魔稱號 + 裝備名稱 + [原始總洞數]`。
- 名稱範例：`+9 兩倍海葵的 巨大雙手劍 [2]`；最後的 `[2]` 永遠代表物品資料中的原始總洞數，不是已插卡數或剩餘洞數。
- 左鍵單擊背包或裝備欄物品會開啟獨立詳細視窗，包含圖示、能力、官方說明、精煉、損壞狀態、卡片插槽與附魔區。
- 卡片圖示滑鼠提示只顯示卡片名稱；左鍵單擊可切換到卡片能力介紹。
- 背包裝備左鍵雙擊為穿戴；裝備欄左鍵雙擊為卸除。單擊與雙擊使用延遲判定，不會同時觸發兩種操作。
- 舊存檔的堆疊裝備會拆成獨立實例；精煉、卡片、損壞與附魔會跟隨該件實例保存。舊 `equipmentCards`／`socketedCards` 會自動遷移。
