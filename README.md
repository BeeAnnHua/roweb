# RO_WEB 0.9.82FO

基準：0.9.82FN。

本版修正：
- 自動戰鬥設定改為固定外框；只有中央內容區捲動，底部「套用戰鬥設定」固定可見。
- 當前地圖怪物篩選預設收合，避免大量怪物選項撐爆視窗。
- 右上角新增「掛機」快速開關；啟用時按鈕點亮並顯示順時針流光，與實際自動戰鬥狀態同步。
- 自動目標權威統一：手動點怪 > 目前有效鎖定 > 攻擊者 > 威脅目標 > 最近怪物。
- 有效鎖定存在時不因其他怪物靠近而來回切換；手動點地面可暫停自動追擊。
- 蒼蠅翅膀、瞬間移動與其他傳送會清除舊目標、舊路線及待完成技能；快捷技能不再找回傳送前怪物。
- 雙手劍加速可正確辨識 `2hSword`、`twoHandSword` 等雙手劍武器代碼。

完整沿用 0.9.82FN 的多段總傷大字、最終傷害停留 3 秒，以及單次 100 件安全批次分解。
