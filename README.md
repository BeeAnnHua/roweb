## RO_WEB 0.9.82HL — 舊版 Tooltip 與貨幣事件強化修正版

本版以 0.9.82HK 為正式基準，修正背包中「消耗品有名稱，但裝備／一般道具沒有提示」及右上貨幣列無法展開完整數字的早期 UI 相容問題。

### 本版重點
- 找到消耗品看似正常的真正原因：消耗品舊程式本來就有原生 `title`，裝備與一般道具沒有；自訂 Tooltip 又會被動態提高層級的遊戲視窗遮住。
- 消耗品、裝備、一般道具與已穿戴裝備現在全部同時具有自訂提示與原生名稱備援。
- 自訂 Tooltip 提升到全域最高 UI 層，背包、裝備視窗或其他舊視窗位於前景時仍可顯示。
- 黯淡冰晶武器提示完整列出卡片及第4／3／2洞附魔名稱；點擊附魔石查看正式圖片與效果的功能維持正常。
- 貨幣列改由 document capture 階段接收 `pointerup`／`click`，不再依賴容易被舊 HUD 程式攔截的 bubble click。
- 「持有貨幣」視窗完整顯示 Zeny、藍寶石與紅寶石，並保持開啟直到按 ×、點擊外部或按 Escape，不會再六秒自動消失。
- 完整保留 0.9.82HK 的玩家升階教學、NPC 正式文字、地圖固定滾輪、一般裝備附魔介紹與出生測試補給移除。

歷史更新／測試／稽核紀錄已續寫至 `HISTORY_UPDATE_AUDIT_LOG_THROUGH_0.9.82HK.txt`。

### 從 0.9.82HK 使用增量包更新
覆蓋檔案後，請在專案根目錄執行一次 `APPLY_0.9.82HL_CLEANUP.bat`，移除上一版留在根目錄的 HK 報告與清理腳本。完整包不需要執行。
