## RO_WEB 0.9.82HX — 大量轉蛋防回檔／手動存檔讀回驗證

本版修正大量開啟 MVP 幸運轉蛋後，按存檔再 F5 仍回到開箱前數量的風險。

- 手動存檔會先結算所有已排入佇列、尚未完成的轉蛋，再建立角色快照。
- 每 256 次開箱建立一次耐久檢查點；最後一批完成時立即保存。
- 「存檔」按鈕會等待 localStorage 或 IndexedDB 實際寫入並讀回驗證後，才顯示「已存檔」。
- 使用者主動按存檔時會接管目前分頁的寫入租約，避免看不見的舊分頁鎖讓存檔被拒絕。
- localStorage 空間不足時不再整次失敗，會改以 IndexedDB 耐久存檔保存。
- HW 的 MVP 單件絕對機率與所有既有功能完整保留。
- 後續版本請以 0.9.82HX 為正式基準。
