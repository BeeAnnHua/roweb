# RO_WEB 0.9.82FY

本版本以 **0.9.82FX** 為基準，修正進階屬性面板展開後造成戰鬥卡頓、視窗關閉後仍在背景持續重繪，以及部分手機／電腦偶發掉幀與發熱問題。

## 本版效能修正

- 找到進階屬性面板的主要卡頓來源：`updatePlayerUI()` 原本會在每次攻擊、扣血、回復與 EXP 變化時，完整重建進階屬性的大量 DOM。
- 素質視窗關閉時，素質與進階屬性完全停止背景更新；保留三角形展開偏好，重新開窗時才刷新。
- 素質、裝備、卡片、Combo、Buff 或戰鬥衍生值沒有改變時，不再重畫進階屬性。
- 使用滑鼠滾輪或手機手勢捲動進階內容時延後重繪，並保留捲動位置與已展開的細項。
- 隱藏中的職業欄與技能欄不再隨每次戰鬥更新；開啟視窗時才立即同步最新資料。
- 快捷欄加入內容簽章，內容與數量不變時不再重建十格 DOM。
- HUD 文字與 HP／SP／EXP 填色只有數值真正變化時才寫入 DOM。
- 進階面板移除即時背景模糊；手機／觸控裝置停用固定 UI 的 backdrop blur，降低 GPU 合成負擔與發熱。

## 保留的 FX 統一效果 Runtime

- 910 張卡片、141 件啟用裝備 Script、784 組 Combo 共用 `CardRuntime + EffectRuntime`。
- 現有資料使用的 142 種 rAthena bonus 指令均有解析與實際消費端。
- 未來新增物品只要使用已支援 Script 指令，會自動進入統一效果管線；未知指令會由 diagnostics 與發行稽核攔下。
- 保留監視者卡片、急速衝刺鎧甲、自然／補品恢復、四轉 HP／SP、完整插卡／拆卡，以及掛機資源不足 15 秒防卡死。

請以 HTTP 伺服器啟動，避免瀏覽器直接開啟檔案造成 CORS 問題。Windows 可執行 `START_RO_WEB.bat`。

- 召喚物控制視窗改為統一狀態面板：坐騎／龍、獵鷹、狼、生命體、元素精靈及獨立召喚物皆會顯示，不再開啟空白。
- 狼與獵鷹可同時存在；移除互斥與自動解除，並同步修正技能說明。
- 盧恩騎士／盧恩龍爵三轉後不再透過二轉騎乘術切換龍；龍駕馭解鎖後於召喚物控制切換。
