彼岸花仙境 / RO_WEB V0.9.85K
跨裝置雲端角色保護修正

目的：
- 防止手機→電腦、Chrome→Edge、127.0.0.1→GitHub Pages 等不同 Origin 沒有本機快取時，
  因雲端完整 save_data 未取得而載入 Lv1 預設角色並反寫覆蓋。

核心規則：
1. 雲端角色進場前必須成功查詢目前 account_id + character_id。
2. 已有進度角色若拿不到完整雲端 save_data，禁止進場、禁止存檔。
3. 新建立角色第一次進場會先建立並驗證完整雲端存檔，成功後才允許遊玩。
4. 若原瀏覽器握有比雲端更新的有效本機進度，會先自動修復同步到雲端並驗證，成功後才進場。
5. 雲端尚未驗證時 saveGame() 有保護鎖，禁止 Lv1 fallback 覆蓋。
6. 所有相關 JS cacheKey 升到 0.9.85K，避免 GitHub Pages / 瀏覽器沿用舊快取。

測試順序：
A. 先在目前「資料正確」的本機瀏覽器套 K 版，進入 Lv240 基因角色。
   - 若能正常進遊戲，代表本機正確進度已成功驗證同步到雲端。
   - 若被擋住，請截圖錯誤訊息；K 版會保護資料，不會用 Lv1 覆蓋。
B. A 成功後再上傳 GitHub Pages。
C. 用無痕視窗 / 第二瀏覽器 / 手機登入同一 Player ID 與角色，應直接讀到相同等級職業。

Supabase：本版不需要新增 SQL。
