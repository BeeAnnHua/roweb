彼岸花仙境 / RO_WEB V0.9.86B
瀏覽器登入容量安全 + 聊天名稱 UI 修正

安裝：
1. 以目前 V0.9.86A / 最新完整 RO_WEB 為基準。
2. 將本 Patch 內容覆蓋到 RO_WEB 根目錄。
3. 不需要執行新的 Supabase SQL。
4. GitHub Pages 更新後建議 Ctrl+F5。

本版修正：
- Supabase Auth Session 改存 IndexedDB，避免角色 localStorage 太大導致 sb-*-auth-token QuotaExceededError。
- 第一次啟動會自動讀取並遷移舊 localStorage Supabase Session；不需要玩家先清除網站資料。
- 若 localStorage 已滿，RO account 選擇狀態可暫存於 sessionStorage，避免登入後無法進角色選擇。
- 註冊中的 Email / 遊戲帳號 pending 資料在 localStorage 不可寫時會退到 sessionStorage。
- 不自動刪除任何既有角色主存檔、安全備份或 IndexedDB 角色資料。
- 世界聊天玩家名稱改為純文字可點，不再顯示按鈕外框。
- 長角色名稱自動省略，點擊玩家資訊窗仍顯示完整名稱。
- 預留 GM / VIP 名稱樣式 hook（本版尚未啟用身分特效）。

既有玩家遇到 QuotaExceededError：
- 請勿先清除網站資料。
- 先更新到本版後重新整理，再重新登入/驗證。
