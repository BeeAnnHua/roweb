彼岸花仙境 RO_WEB V0.9.88B2
長時間掛機 Memory Recycle / 30 分鐘自動分解

升級基準：V0.9.88B1

安裝：
1. 關閉遊戲頁面。
2. 將本 Patch 內所有檔案與資料夾直接覆蓋到目前 V0.9.88B1 專案根目錄。
3. 重新上傳 GitHub Pages / 靜態主機。
4. 建議 Ctrl+F5 強制重新整理一次。

本版不需要執行 Supabase SQL。

使用自動分解：
- 打開背包，按下「自拆」進入標記模式。
- 點擊要自動分解的物品，左上綠色勾勾代表已標記。
- 再按一次「自拆」離開標記模式；標記會保留在角色存檔。
- 自動掛機每連續 30 分鐘執行一次；停止掛機後計時歸零。
- 鎖定、穿戴、受保護、MVP 轉蛋等物品永遠不會被自動分解。

MVP Memory：
- HTTP/HTTPS MVP Atlas 優先 ImageBitmap + close()；file:// 自動使用相容的 HTMLImageElement。
- 資源採每幀小量漸進回收，不會每 10 分鐘做一次大清理。
