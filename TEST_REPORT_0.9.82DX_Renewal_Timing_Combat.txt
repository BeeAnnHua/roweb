正式實作：
- DEX／INT Renewal 變動詠唱公式：1 - sqrt((DEX×2+INT)/530)
- DEX×2+INT >= 530 時，僅變動詠唱可歸零；固定詠唱仍保留。
- 固定詠唱百分比減免只採最高有效值，不相加。
- 變動詠唱、固定詠唱、共通後延遲、獨立冷卻、移動硬直分離。
- 主動技能預設移動硬直 300ms，再加技能 DB AfterCastWalkDelay。
- 瞬發主動技能最低動作鎖 100ms。
- CastTimeFlags／CastDelayFlags 會先判斷是否忽略 DEX、狀態或裝備／卡片修正。
- 裝備、卡片、附魔、Buff 共用同一 Timing Modifier Resolver。

三、ASPD 193 與物理技能動作鎖
-----------------------------
ASPD 上限：193

實際數值測試：
- ASPD 150：普通攻擊間隔 1000ms；零延遲物理技能動作鎖 570ms
- ASPD 190：普通攻擊間隔 200ms；零延遲物理技能動作鎖 170ms
- ASPD 193：普通攻擊間隔 140ms；零延遲物理技能動作鎖 140ms

只有同時符合以下條件的物理技能受 ASPD 動作鎖加速：
- 變動詠唱 0
- 固定詠唱 0
- 技能獨立冷卻 0
- AfterCastActDelay 0

物理技能使用目前武器 Attack 動畫；魔法、治療、Buff、Debuff、支援與施術使用 Cast。

四、戰鬥公式共用層
------------------
正式接入與測試的 Renewal 共用階段：
- 幸運閃避 → 暴擊 → HIT/FLEE
- HIT-FLEE 命中率限制 5%～100%，移除舊的額外 +80。
- 暴擊必定命中，但仍可能先被幸運閃避擋下。
- 一般暴擊完整套用 bCritAtkRate。
- 可暴擊技能套用一半 bCritAtkRate。
- C.RATE 最終暴擊倍率：1.4 + C.RATE/100。
- 目標暴擊傷害減免在最終暴擊倍率之後套用。
- Status ATK、Weapon ATK、精煉、Equipment ATK、Mastery ATK、P.ATK。
- MATK、S.MATK、H.Plus。
- RES／MRES 與硬／軟 DEF／MDEF 分離。
- 主手／副手普通攻擊；主動物理技能預設使用主手。
- 拳刃追加段與 TF_DOUBLE。
- 武器體型修正。
- 攻擊屬性／防具屬性與屬性等級。
- 種族、體型、Boss／NonBoss、近距離／遠距離。
- 裝備、卡片、附魔、Buff 的增傷、減傷、破 DEF／MDEF、破 RES／MRES。
- 技能 DB DamageFlags.Critical 自動進入共用 Critical Resolver。
