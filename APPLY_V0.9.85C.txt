彼岸花仙境 / RO_WEB V0.9.85C 安裝說明
========================================

基準：你剛上傳並已實測 V0.9.85B 信箱成功的最新 RO_WEB。

【1】先更新遊戲檔
把 Patch 內 index.html、gm_center.html、css、js 等相對路徑覆蓋到 RO_WEB 根目錄。

【2】Supabase 只需再新增一個 New query
SQL Editor -> New query
貼上：supabase/V0.9.85C_MAIL_UI_OPERATIONS.sql
按 Run。
舊的 V0.9.84C / V0.9.85B Query 不要刪也不用覆蓋。

正常結果：Success. No rows returned（或 Success）。

【3】重新整理遊戲（建議 Ctrl+F5）
右上功能列應固定 4 x 3：
第一行：人物背包｜裝備欄目｜地圖傳送｜城鎮傳送
第二行：素質配點｜技能配點｜拍賣行｜活動
第三行：信箱｜統計｜召喚物｜掛機設定

拍賣行 / 活動：目前只顯示「尚未開放」，沒有正式功能。
原本下方大型「掛機」按鈕保留，負責開始/停止掛機。

【4】信箱測試
- 一般玩家右上 12 格不再有 GM。
- 領取附件後按鈕立即變為「已領取」且不能再按。
- 一鍵領取：依序安全領取所有可領附件，每封仍經過角色雲端存檔驗證。
- 刪除已讀：只刪已讀且安全可刪郵件；任何尚未領取附件的已讀郵件都會保留。
- 歡迎信原本畫面上的字面 \n\n 會修成真正換行。

【5】GM CENTER
GM 不再佔右上玩家功能格。
只有目前選中的 RO account 經 Supabase 驗證為 active GM 時，信箱工具列才顯示「GM CENTER」。
一般玩家不顯示。
