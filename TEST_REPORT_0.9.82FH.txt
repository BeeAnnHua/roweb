RO_WEB 0.9.82FH — Window Size / Mobile Quick Slots / Compact UI
================================================================

Release scope
-------------
1. Every game window and supported detail modal receives a Large / Medium / Small cycle control.
   - Large: 100%
   - Medium: 75%
   - Small: 50%
   - Default: Large
   - Per-window setting is stored in player.uiWindowSizes with local fallback.
2. Mobile/coarse-pointer skill and consumable dragging is disabled.
3. Skill and consumable detail dialogs can assign directly to quick slots 1~0.
4. Passive/unlearned skills are blocked; zero-count consumable slots remain gray and recover automatically.
5. Monster distribution shows names only; Boss/MVP live/respawn state remains.
6. Touch monster information is embedded inside the Map/Teleport window and scrolls internally.
7. System log toolbar contains Save/Clear Save; current city/region is displayed above coordinates.
8. Equipment detail provides Equip/Unequip with existing restriction checks.
