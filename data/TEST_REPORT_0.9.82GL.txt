IMPLEMENTED
-----------
1. Server Config gradeMaterialDropRate uses percentage integers:
   100=1x, 200=2x, 50=0.5x, 0=disabled.
   It only scales independent bonus grade-material drops. Original rAthena drops,
   cards and MVP drops are untouched.
2. Teleport monster list supports desktop hover / mobile tap drop lookup.
   Original, MVP and grade-material bonus drops are separated. Data is cached lazily;
   there is no one-second polling timer and no Auto Battle / AI tick integration.
3. Enchant Grade window now opens before async data readiness checks, removes all hidden
   states safely, and shows loading/no-eligible-equipment/error messages instead of doing nothing.
4. All six implemented cities have the same account storage endpoint. Capacity is 200 slots.
   Filters: Consumables / Equipment / Items.
5. Backpack visible layout is 5 columns x 6 rows = 30 slots.
6. Normal and trait status allocation uses requestAnimationFrame UI batching and delayed save.
   Pointer/touch/mouse events are isolated from map controls; current target, rotation and
   Auto Battle controller are preserved.
7. Feint Bomb target/shape/timing remains based on the Renewal profile. RO_WEB final ratio
   receives a player-requested x2 correction because the prior in-game result was too low.
8. Plagiarism/Reproduce skill instances waive original-profession combat-resource costs only.
   Native profession skills still consume their resources. SP, item, weapon, range, timing and
   cooldown rules remain active.
