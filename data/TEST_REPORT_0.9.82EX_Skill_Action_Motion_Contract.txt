RO_WEB 0.9.82EX — Skill Action Motion Contract
==================================================

User rule
---------
- Buff / Heal / Debuff / Support / Performance: weaponless Cast PNG/Atlas.
- Every monster-damaging skill: equipped-weapon Attack PNG/Atlas.
- Passive: no action. Toggle off: no action. Toggle on: Cast.

Root cause
----------
27 Buff skills retained legacy Skill Core type=Weapon. The old motion selector treated
that legacy field as physical offense even when the executable Runtime handler was Buff.
Examples: Endure, Attention Concentrate, Adrenaline Rush, Weapon Perfection, Enchant Poison.

Fix
---
1. getRuntimeSkillActionMotion now uses getRuntimeSkillUiType / Runtime handler as authority.
2. Damage handlers resolve to Attack regardless of physical/magic/misc/ground/chain/combo.
3. Non-damage active handlers resolve to Cast.
4. Removed extra hard-coded Cast playback in Heal, Chain Magic and Combo Sequence.
5. Headless fallback no longer invokes DOM attack animation when document is unavailable.
