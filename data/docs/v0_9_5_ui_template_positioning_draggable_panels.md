# RO_WEB v0.9.5 UI Template Positioning & Draggable Panels

## 本版目標

本版重點是把素質欄與技能欄改成「UI 圖片作為模板」，不再重複輸出圖片裡已經存在的固定文字。

## 更新內容

1. 素質欄改用 `images/ui/panels/status_panel.webp` 當完整模板。
2. 素質欄只填入：六大素質數字、`+` 配點按鈕、戰鬥數值、剩餘點數。
3. 移除重複的 STR / AGI / VIT / 攻擊力 / 防禦力等文字，避免和 UI 圖疊字。
4. 技能欄繼續使用 `images/ui/panels/skill_panel.png` 當模板，微調五格技能列定位。
5. 技能欄只填入：技能 icon、技能名稱、Lv、狀態、`+` 升級按鈕、技能點數數字。
6. 素質 tooltip 與技能 tooltip 保留，不直接佔用面板版面。
7. 面板拖曳系統改用 pointer events，支援滑鼠與觸控拖曳。
8. 面板位置會記錄到 localStorage，下次開啟保留位置。
9. 拖曳時保留部分面板在畫面內，避免拖到找不回來。

## 不做項目

- 本版仍不做負重系統。
- 不顯示 MaxWeight。
- 不讓 STR 影響負重。

## 測試重點

1. 打開素質欄，確認沒有重複文字與文字重疊。
2. 點 STR / AGI / VIT / INT / DEX / LUK 旁邊的 `+` 是否能正常配點。
3. 素質數字與戰鬥數值是否填在 UI 圖預留位置。
4. 滑鼠移到素質列與數值時，tooltip 是否顯示。
5. 技能欄五格是否貼合 UI 圖。
6. 轉職前技能欄仍顯示初心者提示；轉職劍士後才顯示劍士技能。
7. 技能 tooltip 是否正常。
8. 技能欄、素質欄、物品欄、地圖欄等視窗是否可拖曳。
9. 重新整理後，視窗位置是否保留。
