# RO_WEB V0.9.72g - Mobile Position Save + Touch Boundary Fix

## 更新重點

1. Position 座標每 60 秒自動存檔一次。
2. F5 / 關閉頁面 / 切到背景時強制補存。
3. 不在自動掛機每次移動到點時存檔，避免未來接雲端後寫入過於頻繁。
4. 手機版角色與怪物定位加入 getBoundingClientRect 反校正，避免 CSS zoom 導致視覺腳底座標被壓縮。
5. 戰鬥紀錄透明 UI 不阻擋地圖點擊；真正互動元件仍阻擋。

## 測試重點

- 手機版點擊畫面下方邊界，角色應能往下走到底。
- 手機版連續點擊下方角落，不應出現往上修正。
- 自動掛機 1 分鐘後重新整理，座標應回到最近一次定時保存的位置。
- 使用蒼蠅翅膀仍立即存檔。
