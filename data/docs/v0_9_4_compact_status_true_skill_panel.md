# RO_WEB v0.9.4 Compact Status & True Skill Panel

## 更新重點

1. 素質欄改為精簡顯示，只保留 STR / AGI / VIT / INT / DEX / LUK、剩餘素質點與主要戰鬥數值。
2. 移除負重 / MaxWeight 的顯示與計算，RO_WEB 目前不做背包重量系統。
3. 素質說明改成 tooltip：滑鼠移到素質名稱，或手機點一下素質名稱，可查看該素質影響內容。
4. 技能欄改為更貼合 `images/ui/panels/skill_panel.png` 的固定尺寸面板。
5. 技能欄尺寸改為 500 × 645，保留原圖比例並避免 1280 × 720 畫面爆版。
6. 技能資料改為 hover / 點擊 tooltip 顯示，包含技能等級、類型、前置需求、SP、倍率、持續時間與說明。
7. 保留 v0.9.3 快捷欄邏輯：未轉職不顯示劍士技能，轉職並學會後才加入快捷欄候選。

## 測試重點

- 開啟素質欄後，畫面不再出現大段說明文字。
- STR 等素質名稱 hover / 點擊能顯示 tooltip。
- 素質欄不再顯示 MaxWeight / 負重。
- 技能欄大小與背景 UI 更貼合，不再使用原本 3 欄網頁卡片排版。
- 技能 icon / 名稱 hover / 點擊能顯示技能詳細說明。
- 初心者階段仍不顯示劍士技能。
- 轉職劍士後，技能樹與技能配點正常。
