3. ENCHANT GRADE / MATERIAL EXCHANGE WINDOW
--------------------------------------------
ROOT CAUSE 1:
The GK grade stylesheet had literal "\\n" text around the whole rule block.
The browser could not correctly parse the modal positioning rules, so JavaScript
could remove the hidden state while the window remained outside the visible game area.

ROOT CAUSE 2:
.grade-layout had an author display:grid rule that overrode the HTML hidden state.
The Material Exchange tab became active internally, but the Grade panel remained
visible and pushed the recipe panel below the viewport.

PASS  Literal backslash-n sequences removed from CSS.
PASS  Grade overlay has valid fixed positioning and z-index 1000002.
PASS  Runtime applies essential fixed modal geometry inline as a cache-safe fallback.
PASS  No eligible equipment: window opens and shows the empty equipment message.
PASS  Grade and Material Exchange panels explicitly honor [hidden].
PASS  Direct Material Exchange opens the exchange panel and creates all 6 recipes.
PASS  Town NPC buttons use one direct openEnchantGradeNpcWindow helper.
