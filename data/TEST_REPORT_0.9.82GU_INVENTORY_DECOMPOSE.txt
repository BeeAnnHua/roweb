RO_WEB 0.9.82GU — 安全數量分解測試報告
============================================================
基準版本：0.9.82GT
更新版本：0.9.82GU

一、功能內容
------------------------------------------------------------
1. 背包下方「分解」不再立即執行，先開啟數量確認視窗。
2. 玩家可自行輸入本次分解數量；預設 100，最大值不超過目前可分解數量。
3. 物品／裝備資料視窗右上角新增「分解」按鈕：
   - 背包裝備：同時顯示「分解」與「穿戴」。
   - 消耗品：同時顯示「分解」與「使用」。
   - 卡片／雜物：可直接由資料窗分解。
   - 穿戴中裝備：分解按鈕停用，必須先卸下。
4. 鎖定物品、穿戴中裝備、manualUseOnly／mvp_gacha／noDecompose 道具不可分解。
5. 分解採單次候選掃描、單次陣列重建、單次 saveGame，不逐件執行。

二、精準扣量測試
------------------------------------------------------------
PASS  蘋果 3,000，分解 100，剩餘 2,900。
PASS  傑勒比結晶 3,000，分解 100，剩餘 2,900。
PASS  輸入大於持有量時，自動限制為可用數量。
PASS  輸入 0、空值或非數字時，安全回到預設 100。
PASS  裝備分解只移除指定 instanceId 的 1 件，不影響同 ID 其他裝備。

三、防誤刪測試
------------------------------------------------------------
PASS  鎖定物品不可分解。
PASS  穿戴中裝備不可分解。
PASS  MVP 幸運轉蛋不可進入分解候選。
PASS  分解失敗時回復背包與 Zeny 快照並重新存檔。
PASS  分解按鈕有交易鎖與 650ms 防連點冷卻。

四、大量物品效能
------------------------------------------------------------
PASS  1,000,000 件堆疊分解 500,000 件，結果精準保留 500,000 件。
PASS  Node Runtime 模擬耗時約 0.06ms（實際設備依存檔與 UI 更新略有差異）。
說明：演算法只走訪背包堆疊列，不會建立 500,000 次逐件迴圈。

PASS  裝備數量固定為 1。
PASS  堆疊物品預設數量為 100，可自行修改。
PASS  預覽文字顯示分解數量、預估 Zeny 與剩餘數量。
PASS  MVP 轉蛋的分解按鈕顯示但停用並提示受保護。
