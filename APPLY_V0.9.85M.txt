彼岸花仙境 / RO_WEB V0.9.85M
雲端 Lv1 污染修復 + 跨瀏覽器遠端權威 + 齒輪手動存檔 UI 修正

前置條件：Supabase 已成功執行 V0.9.85L_CLOUD_CHARACTER_SAVE_RPC.sql。
本版不需要新增 SQL。

安裝：
1. 覆蓋本 Patch 到目前 V0.9.85L 專案。
2. Ctrl+F5。
3. 先在仍保有正確高等角色資料的原瀏覽器 / 127.0.0.1 進入該角色。
4. V0.9.85M 會辨識「雲端版本號較新但內容為 Lv1/損壞」的舊污染快照，允許正確高等角色透過 L 版安全 RPC 修復雲端。
5. 開啟齒輪 -> 手動存檔，再確認系統訊息顯示本機與雲端同步完成。
6. 將同一版上傳 GitHub Pages，Ctrl+F5 後重新登入。

重要規則：
- 雲端已有正常完整角色時，新瀏覽器以雲端為權威；不讓該瀏覽器舊 Lv1 localStorage 蓋過遠端。
- 只有「本機是已建立角色（非 Lv1 初學者）」且遠端缺失 / 明顯 Lv1 回退 / 損壞時，才允許受控修復。
- 對話欄右上「存檔 / 角色 / 清存檔」已移除。
- 手動存檔移至右上齒輪「遊戲設定」。
