V0.9.87E 安裝順序
==================

基準：V0.9.87D（使用者提供 roweb(7).zip）

1. Supabase SQL Editor -> New query
2. 執行：supabase/V0.9.87E_VIP_OFFLINE_ARM_15S.sql
3. 確認結果：V0.9.87E_VIP_OFFLINE_ARM_15S_READY / 15 / 1920
4. 再上傳/覆蓋 V0.9.87E 前端 Patch。

V0.9.87D 的拍賣 1 分鐘 SQL 已執行者不用重跑。
V0.9.87A 拍賣 SQL、VIP Q SQL、Legacy Rescue SQL 都不用重跑。

測試：
A. VIP 角色在野外按「掛機」 -> Battle Log 應出現「VIP 離線掛機已登記」。
B. 不按「停止掛機」，直接關閉頁面；至少離線 5 分鐘後用同一角色登入。
C. 虛擬擊殺應為 floor(離線秒數 / 15)，8 小時上限 1920。
D. 普通下線（未開掛機）不應出現離線收益。
E. A 角色掛機離線後先登入 B 角色：B 不領走；再登入 A 才可領。
F. 拍賣場開啟後，右上 HUD 與左上角色資訊不得遮住拍賣視窗。
