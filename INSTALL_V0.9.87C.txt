彼岸花仙境 RO_WEB V0.9.87C — Legacy Warehouse Rescue

基準：V0.9.87B 完整版
SQL：不需要執行任何新 SQL

安裝：
1. 將本 ZIP 內容直接覆蓋到 V0.9.87B 專案根目錄。
2. 不要清除 localStorage、sessionStorage 或 IndexedDB。
3. 讓發生倉庫遺失的玩家使用「原本改雲端前的同一台電腦＋同一個瀏覽器」。
4. 登入正確 Player ID，進入遊戲後打開「帳號共用倉庫」。
5. 點倉庫上方「救援舊倉庫」。
6. 等待掃描完成，核對候選的裝備數、道具數與預覽名稱。
7. 選擇正確候選，勾選歸屬確認，再按「確認合併復原」。

安全規則：
- 掃描不會修改或刪除舊資料。
- 復原採合併，不會整包覆蓋目前雲端倉庫。
- 裝備保留精煉、卡片、附魔與 instanceId。
- 同一候選成功復原後會留下 receipt，禁止重複匯入。
- 明確屬於其他 Supabase Account UUID 的候選會阻擋。
- 合併後超過 200 格會整批停止，不寫入。
- Cloud 帳號會先等待 Supabase shared_save 寫入成功，再更新本機快取。
