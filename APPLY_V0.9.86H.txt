彼岸花仙境 V0.9.86H — 本機角色雙儲存救援 + 完整 Email 顯示

基準：使用者最新 roweb(2).zip / V0.9.86G

更新內容：
1. 雲端角色缺失救援同時掃描 localStorage + IndexedDB。
2. IndexedDB 掃描 ro_web_offline_save_v1 / player_saves 全部耐久存檔列。
3. 僅接受 save envelope 內 accountId 與目前 Supabase account_id 完全相同，且 characterId 為原角色 UUID 的角色。
4. 只允許已建立進度角色（非預設 Lv1 初學者）進入自動復原提示。
5. localStorage / IndexedDB 有同一角色多份備份時，以 saveVersion，再以 savedAt 選最新一份。
6. 帳號選擇頁「目前登入 Email」顯示完整 Email；OTP/重寄提示仍可維持遮罩。

Supabase：
- 本版不需要新增 SQL / New query。
- 必須已經執行過 V0.9.85N_CLOUD_CHARACTER_LOCAL_RECOVERY_RPC.sql（目前專案基準已包含）。

測試方式（100011 朋友帳號）：
- 覆蓋 Patch 後 Ctrl+F5。
- 用朋友原本玩角色的同一個瀏覽器 + 同一個網站網址登入 100011。
- 若 localStorage 或 IndexedDB 仍保存「身分相符且有進度」的角色，角色選擇前會跳出「偵測到可復原的本機角色」。
- 按「復原至雲端」後才會呼叫 Supabase RPC；掃描本身只讀不寫。
- 若完全沒有提示，表示這個網站 Origin 的 localStorage / IndexedDB 都沒有符合 100011 account_id 的可復原角色。

注意：
- 不要先建立新角色覆蓋 SLOT。
- 本版沒有加入 VIP 離線掛機 / EXP / 掉寶加成。
