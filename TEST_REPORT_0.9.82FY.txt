RO_WEB 0.9.82FY — 進階屬性／自動掛機 UI 效能修正測試
============================================================
基準版本：0.9.82FX
結果：PASS

一、根因
- updatePlayerUI() 原本會在攻擊、受傷、恢復、EXP 等高頻事件中無條件執行 updateStatusUI()。
- 進階屬性三角形展開後，updateStatusUI() 會反覆刪除並重建大型進階屬性 DOM。
- 關閉素質視窗只隱藏畫面，statusAdvancedExpanded 仍為 true，因此背景仍持續重建。
- 使用者滾輪／手勢捲動時若遇到重建，會同時產生 layout、paint 與 scrollTop 抖動。

二、修正
- status-window 關閉時取消所有待處理素質更新，背景不再建立進階屬性 DOM。
- 角色衍生值、裝備實例、卡片、Buff、頁籤與展開狀態未變時，跳過完整素質重建。
- 素質更新最短間隔 120ms；進階內容滾動後等待 650ms 靜止才允許重繪。
- 重繪後恢復 scrollTop 與所有 details 展開狀態。
- 隱藏中的 job-window／skill-window 不再於戰鬥中重建，開窗時才同步。
- 快捷欄內容簽章相同時跳過十格 DOM 重建。
- HUD 文字與 HP/SP/EXP 填色值相同時不重寫 DOM/CSS。
- 移除進階屬性背景 blur；手機／觸控環境停用固定 UI backdrop-filter。

三、效能測試 Harness
- 連續 100 次相同 updatePlayerUI()：
  * 素質更新請求 1 次
  * 職業欄重建 1 次
  * 技能欄重建 1 次
- 隱藏視窗後改變資料：
  * 素質背景更新 0 次
  * 職業欄背景重建 0 次
  * 技能欄背景重建 0 次
- 快捷欄首次建立後再呼叫 100 次相同內容：新增 DOM 節點 0。
