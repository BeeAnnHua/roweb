1. Supabase SQL Editor → New query。
2. 執行 supabase/V0.9.87J_OFFLINE_CONTINUITY_V1.sql。

3. 將本 Patch 內容覆蓋目前 V0.9.87I 最新版。

5. 不要清除 localStorage / IndexedDB。

第一輪測試：
A. 在線角色先按一次存檔。
B. 齒輪 → 切換本地遊玩 → 左上狀態應變 OFFLINE。
C. OFFLINE 可掛機、EXP、Zeny、普通掉落；精煉／附魔／拍賣／倉庫／信箱領取應被阻擋。
D. OFFLINE 玩一段後點左上 OFFLINE 或齒輪「切換線上模式」。
E. 系統會先保存本機，再比對 revision，成功後狀態變 CLOUD。
F. OFFLINE 時直接關網頁，再開啟時若靜態網頁資源可載入，會優先使用已驗證本機角色進場。

安全規則：
- 若離線期間同一角色已在其他裝置／分頁寫入雲端，切回線上會停止合併並保持 OFFLINE。
- 不會把兩份背包／裝備直接相加。
- 衝突時請勿清網站資料，保留本機存檔再處理。
