彼岸花仙境 RO_WEB — V0.9.86P
Legacy 多角色進場 Hand-off 修正（累積 O + P，可直接由 V0.9.86N 升級）

【從朋友實機影片確認的症狀】
- SLOT 1 十字軍可以正常進入。
- SLOT 2 / 3 / 4 點「進入遊戲」後，Loading 只到約 5~8% 就回角色選擇頁。
- 因此錯誤發生在角色存檔載入（約 69%）之前，不是背包/技能/地圖舊資料本身造成。

【P 修正】
1. 玩家點下的 Character ID Entry Token 在雲端 bind 時具有最高優先權。
2. 不再依賴 localStorage 裡 account.activeCharacterId 必須先成功寫入。
3. Entry Token 使用 sessionStorage + localStorage 短效備援（120 秒、one-shot）。
4. 雲端角色清單重新 bind 後，會先恢復玩家明確點擊的角色，再 rebind SaveManager。
5. Token 驗證後立即消耗，不會造成重新整理自動登入。
6. SLOT 1 既有正常登入流程保留。

【同包包含 V0.9.86O】
- Legacy 背包 null / 舊 inventory shape 相容。
- 舊 skills / quickbar / hotkeys migration。
- 舊角色 normalize 失敗時顯示可回報的錯誤訊息。
- O 版 cache-bust 與既有舊角色保護。

【SQL】
不需要新增或重跑 SQL。
繼續使用既有 V0.9.86I_LEGACY_BROWSER_CHARACTER_RESCUE.sql 即可。

【安裝】
將本 ZIP 內容覆蓋到目前網站根目錄（保留資料夾結構）。
這是累積 Patch：已是 V0.9.86O 的網站可直接覆蓋；仍在 V0.9.86N 也可直接覆蓋。

1. 先測 SLOT 2 八嘎（樞機主教）。
2. 再測 SLOT 3。
3. 再測 SLOT 4。
4. 最後回測 SLOT 1 十字軍。
