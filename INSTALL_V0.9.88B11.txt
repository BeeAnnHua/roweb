彼岸花仙境 RO_WEB V0.9.88B11 增量更新說明
==================================================

基準版本
--------------------------------------------------
請覆蓋到使用者提供的最新母檔：
roweb(20260817-032930).zip

安裝方式
--------------------------------------------------
1. 先備份目前 GitHub 專案。
2. 將本 Patch 內全部檔案與資料夾覆蓋到 GitHub 專案根目錄。
3. 保留原專案中沒有出現在 Patch 內的所有檔案。
4. Commit / Push 後等待 GitHub Pages 完成部署。
5. 使用 Ctrl+F5 重新載入一次，確認畫面版本為 V0.9.88B11。

Supabase
--------------------------------------------------
本版沒有新增或修改 Supabase Schema / RPC / SQL。
B10 的 LOW_EGRESS SQL 已成功執行即可，不需要重跑。

建議驗證
--------------------------------------------------
1. 可在 Windows 雙擊 CHECK_RO_WEB.bat 執行 B11 專用健康檢查。
2. 登入後手動存檔、切換地圖、關閉頁面再重開，確認進度正常。
3. 讓傭兵施放光耀之堂，確認治療由傭兵位置與能力正確計算。
4. 觀察 Supabase Egress 每日增量；B10 低流量機制在 B11 完整保留。

本版重點
--------------------------------------------------
- 修復 10 份技能特效 JSON 的非法 Infinity。
- 本機安全備份副本最短每 60 秒寫入一次，主存檔仍即時。
- pagehide / beforeunload / freeze 最終存檔兩秒內去重。
- 修正傭兵光耀之堂延遲 Tick 的施法者錯置。
- 統一 B11 版本與瀏覽器快取標記。
