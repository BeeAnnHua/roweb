彼岸花仙境 / RO_WEB V0.9.85F
雲端帳號隔離 + 帳號選單存檔修正版

基準：V0.9.85E（已包含 V0.9.85C / D / E）

安裝：
1. 關閉遊戲頁面，或至少停止操作角色。
2. 將本 Patch 內檔案覆蓋到 RO_WEB 專案相同路徑。
3. 本版不需要執行 Supabase SQL。
4. 開啟遊戲後建議 Ctrl+F5 強制重新整理一次。

主要修正：
- 同一瀏覽器切換不同 Player ID / 角色，不再沿用上一角色 localStorage / IndexedDB 存檔 key。
- 讀取本機候選存檔時，明確 accountId / characterId 不符者直接拒絕。
- 雲端寫入前增加跨帳號 / 跨角色防護。
- 從「切換帳號 / 登出 / Account Center 進入遊戲」回遊戲時，一律先到 12 格角色選擇。
- 對話欄右上移除：存檔、角色、清存檔。
- 手動存檔移至齒輪選單；切換帳號 / 登出前同步角色與帳號倉庫。

建議測試：
A. 玩家 100010 -> 角色 A，記錄 Zeny / 背包 / 倉庫。
B. 齒輪 -> 切換帳號 -> GM 100001 -> 進入遊戲，必須先看到角色選擇。
C. GM 進角色後資料不得變成 100010 的角色資料。
D. 再切回 100010，仍先到角色選擇，角色 A 資料維持原樣。
E. 同帳號切角色 A/B 各自存檔，互相不得覆蓋。

注意：
若 V0.9.85E 之前已經有某一個測試角色被舊 Bug 寫成另一隻角色的內容，V0.9.85F 會阻止「之後再次污染」，但不會猜測並自動回復已被改寫的舊雲端資料。測試用重複角色可在 12 格角色選擇畫面確認後刪除。
