彼岸花仙境 / RO_WEB V0.9.85B Patch
=====================================
基準：V0.9.84C roweb(註冊網頁完成版)
本 Patch 為累積版：即使已安裝 V0.9.85A 也直接套用即可。

【1】先做 Supabase
Supabase Dashboard -> SQL Editor
執行：supabase/V0.9.85B_MAIL_GM_CENTER.sql

這一步只在安裝/升級版本時做一次。
之後 GM 日常寄信直接使用遊戲內 GM CENTER，不需要每次開 SQL Editor。

【2】覆蓋遊戲檔
把 Patch 內 roweb(目前最新版) 資料夾內容覆蓋到你的最新版同名資料夾。

【3】第一輪測試
A. 一般玩家 / Player ID 100010
- 右上：只能看到「信箱」，不能看到 GM。
- 信箱：應收到「信箱系統正式開通！」。
- 附件：紅寶石 x100。
- 領取後右上紅寶石增加 100，重新整理後不可重領。

B. GM01 / Player ID 100001
- 右上：應看到 GM。
- GM CENTER 可輸入 Player ID 100010。
- 可寄：最多 5 種 Item + Zeny + 藍寶石 + 紅寶石。

【4】重要權限修正
GM 權限現在綁定「目前選中的 RO 帳號」。
即使同一個 Auth Email 底下另有 GM 帳號，一般 Player 帳號也不能使用 GM CENTER。
